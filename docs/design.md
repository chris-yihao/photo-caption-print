# iPhone 照片打印边框一键工具设计

## 目标

在 Mac 上处理从“照片”App 导出的 iPhone 照片。用户完成选片后，将照片放入指定文件夹并双击运行工具，批量生成适合 6×4 英寸冲印的成品。成品完整保留画面，在底部白色信息区显示可用的拍摄信息，且不修改原照片。

## 使用流程

1. 在 Mac“照片”App 中按最早拍摄时间排序，首批选择 100 张。
2. 导出当前可见的编辑版本，并保留可用的位置和描述信息；原片保留在照片图库中。
3. 使用 XnView MP 评分和筛选，将保留照片放入工具的“已选照片”文件夹。
4. 双击运行工具。工具读取元数据、解析地点、排版并生成冲印文件。
5. 用户从“打印成品”文件夹取得 JPEG，并查看 CSV 处理报告。

## 元数据规则

- 优先读取当前导出文件中的 EXIF、XMP、IPTC 和 QuickTime/HEIC 元数据。
- 提取拍摄日期、具体时间、GPS 坐标、拍摄设备品牌与型号。
- 星期几根据拍摄日期计算，不依赖照片内已有字段。
- GPS 转换为“城市＋具体地点”；无法取得具体地点时退回“城市＋区县”。无 GPS 时隐藏地点。
- 设备型号尽量转换为用户可读名称；无法识别时保留原始型号字符串。
- 可使用人工补录 CSV 覆盖或补充日期、时间、地点和设备，但补录不是生成成品的前置条件。
- 所有来源均无某项信息时隐藏该项，不输出“未知”、空标签或多余分隔符。
- 所有信息均缺失时，底部保持纯白。

## 版式与打印输出

- 固定输出为 6×4 英寸、300 PPI：横版 1800×1200 像素，竖版 1200×1800 像素。
- 使用 sRGB、高质量 JPEG，不覆盖输入文件。
- 横图采用居中轻微裁切，并保留左右各 80 像素的窄白边；竖图和正方形照片完整显示、不裁切，比例不一致处以白色留空适配。
- 使用双行纪实布局。第一行显示“年月日 · 星期几 · 具体时间”，第二行显示“城市 · 具体地点 / 设备”。
- 缺失字段时动态删除对应分隔符、重新组合并居中。
- 地点过长时优先省略低价值地址层级；报告保留完整地点。
- 分辨率不足时仍可生成，但必须在报告中标记警告，避免不受控的过度放大。

## 一键工具结构

- `已选照片`：用户放入待处理照片。
- `打印成品`：生成的 6×4 JPEG。
- `人工补录.csv`：可选，按文件名补充或覆盖元数据。
- `处理报告.csv`：记录识别信息、缺失字段、地点解析、像素质量和输出文件。
- 双击入口依次调用元数据读取、地点解析和图像排版。
- 地点解析结果按 GPS 坐标缓存；网络不可用时继续处理，并在报告中记录地点缺失。
- 单张失败不终止整批任务；失败原因写入报告。
- 同名输入通过稳定后缀避免覆盖；重复运行时结果可复现。

## 软件与平台

- 平台：macOS。
- 照片导入与原片管理：Apple“照片”App。
- 选片：XnView MP。
- 元数据：ExifTool。
- 图像画布与文字渲染：ImageMagick。
- 一键入口：本地脚本与 Mac 可双击启动包装，不要求 Adobe 订阅。
- Live Photo 第一版只处理静态图像；视频和动态部分不在范围内。

## 验收标准

- 支持横图、竖图、正方形图、HEIC、JPEG，以及完整、部分缺失、全部缺失元数据的照片。
- 每张成功输出均为对应方向的 6×4、300 PPI JPEG，照片内容未被裁切。
- 每一种缺失组合均无空标签或多余分隔符；全部缺失时底部纯白。
- GPS 正常、无结果和离线均不会阻塞整批处理。
- 长地点、中文、英文和设备型号不会重叠或越过打印安全区。
- 输入照片不被修改；重复文件名不会导致覆盖。
- CSV 报告与实际生成、警告和失败数量一致。
