# 全角日期数字设计

## 目标

改善中文日期中阿拉伯数字与“年、月、日”的视觉协调性，同时保持现有打印版式不变。

## 输出规则

- 只把日期 `YYYY年MM月DD日` 中的数字转换为全角字符。
- 示例：`2017年12月18日` 输出为 `２０１７年１２月１８日`。
- 星期与时间保持现状，例如完整首行输出为：
  `２０１７年１２月１８日 · 星期一 · 11:25`。
- 不添加日期单位周围的额外空格。
- 不改变地点、设备、字号、行距、白边尺寸或横图、竖图、正方形照片的居中算法。
- 缺少拍摄日期时继续不显示日期行，不改变现有缺失信息处理。

## 实现边界

在字幕格式化阶段生成日期后，仅将 ASCII 数字 `0-9` 映射为全角数字 `０-９`。时间另行按原格式生成，因此不会被转换。

## 验证

- 单元测试验证日期数字为全角、时间数字仍为半角。
- 现有字幕、布局和完整测试套件必须继续通过。
- 使用现有实际照片生成预览，确认全角日期在底部白边中的视觉效果和居中位置。
