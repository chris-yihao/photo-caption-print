# 恢复半角日期数字设计

## 目标

恢复项目最开始的紧凑日期数字间距，消除全角数字自身占用完整中文字宽造成的疏朗效果。

## 输出规则

- 日期 `YYYY年MM月DD日` 使用半角数字。
- 示例：`2018年02月15日 · 星期四 · 22:55`。
- 日期数字与 `年、月、日` 之间不添加任何额外空格或像素间隔。
- 时间继续使用半角数字。

## 保持不变

- 竖图照片顶部和左右白边保持 20 像素。
- 竖图文字继续在照片实际底边到画布底边的完整白色区域内上下居中。
- 横图和正方形继续使用当前字幕位置。
- 字号、行距、水平居中、星期、地点和设备格式不变。

## 实现与验证

- 删除日期数字的全角转换，恢复直接使用 `%Y年%m月%d日`。
- 更新字幕和管线精确字符串测试。
- 使用 `IMG_0783.jpeg` 生成预览，确认日期数字间距恢复紧凑，竖图动态居中不变。
- 完整回归测试不得出现与本次修改相关的新失败。
