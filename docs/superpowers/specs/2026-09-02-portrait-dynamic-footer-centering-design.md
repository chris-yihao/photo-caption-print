# 竖图动态底部留白居中设计

## 问题

竖图已改为顶部对齐。当照片按宽度等比例缩放且高度较短时，照片底边与画布底边之间会形成较大的完整白色区域。当前字幕仍只在固定的底部 180 像素内居中，因此文字上方空白远大于下方空白。

## 目标

针对竖图，以照片实际底边到成品画布底边之间的全部白色区域为字幕区域，让可见文字整体的上方和下方留白相等。

## 布局规则

- 竖图动态字幕区域顶部为 `photo_y + photo_height`。
- 竖图动态字幕区域底部为画布底部 `canvas_height`。
- 一行字幕按该区域的可见墨迹垂直居中。
- 两行字幕保持当前字号和行间距，先组成一个文字块，再将整个可见墨迹文字块垂直居中。
- 当区域高度与文字高度奇偶性不同时，允许上下相差最多 1 像素。
- 竖图不再应用固定的“整体上移 3 像素”，因为该偏移会破坏上下留白相等。
- 横图和正方形照片继续使用当前字幕区域及整体上移 3 像素规则。

## 保持不变

- 竖图顶部和左右白边继续保持 20 像素。
- 照片继续等比例缩放，不裁切、不拉伸。
- 日期继续使用全角数字和字体默认字距。
- 星期、时间、地点、设备、字号、水平居中和两行间距不变。
- 缺少信息时的一行或空白布局规则不变。

## 实现方案

复用现有透明字幕层的“绘制、裁切可见墨迹、居中扩展”流程。仅在竖图中把字幕层高度改为从照片实际底边到画布底边，并把最终字幕层合成到照片实际底边；正方形继续使用固定字幕层，横图继续使用直接标注。

## 验证

- 几何不同的竖图分别验证动态字幕区域起点等于照片实际底边。
- 一行和两行竖图输出验证可见墨迹上下留白相差不超过 1 像素。
- 横图和正方形命令位置保持当前值。
- 使用用户截图对应的照片（若能从现有文件夹定位）或同类短竖图生成预览。
- 完整回归测试不得出现与本次改动相关的新失败。
