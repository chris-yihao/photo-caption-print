# 竖图顶部、日期字形与字幕位置设计

## 目标

统一竖图顶部和左右白边，调整日期字形与基线，并将所有照片的底部字幕整体上移 3 像素，同时保持现有打印尺寸、照片比例和字幕内部布局。

## 竖图照片位置

- 竖图顶部白边固定为 20 像素，与左右安全白边相同。
- 竖图保持当前等比例缩放尺寸，不裁切、不拉伸。
- 当照片按宽度缩放后不能填满照片区域高度时，多余留白全部保留在照片下方、字幕区域上方。
- 横图和正方形照片的位置及裁切规则不变。

## 日期格式与间距

- 只把日期 `YYYY`、`MM`、`DD` 转换为全角数字。
- 示例首行：`２０１７年１２月１８日 · 星期一 · 11:25`。
- 时间 `11:25` 保持半角数字。
- 不再添加日期单位的额外像素间距；全角数字与 `年、月、日` 按字体自身的正常字距直接相邻。
- 日期数字不再向下移动 1 像素；数字与 `年、月、日` 使用同一基线。
- `日`之后的分隔符、星期和时间间距保持不变。

## 字幕整体位置

- 底部字幕整体向上移动 3 像素。
- 横图、竖图和正方形照片都应用该移动。
- 一行和两行字幕都应用该移动。
- 两行文字间距、字号、水平居中方式和可见墨迹居中算法保持不变。

## 实现边界

- `captions.py` 在生成日期片段后仅转换日期数字，不转换时间。
- 日期不再需要独立间距或基线处理，`layout.py` 恢复为整行测量和整行绘制，使用字体自身的正常字距。
- 竖图几何只把 `photo_y` 固定为照片区域顶部；照片尺寸计算保持不变。
- 字幕位置在最终布局坐标上统一减 3 像素，不改变行间基线差。

## 验证

- 格式化测试确认日期全角、时间半角。
- 几何测试确认竖图 `photo_y == 20`，并确认横图、正方形不变。
- 命令测试确认日期恢复整行绘制，不再存在日期单位间隔图层或数字下移命令。
- 布局测试确认所有方向和一行、两行字幕均整体上移 3 像素，行间距不变。
- 使用 `IMG_0451.jpeg` 生成实际竖图预览，检查顶部、日期和字幕位置。
- 完整回归测试不得出现与本次修改相关的新失败。
